# Журнал изменений

Здесь записаны изменения навыка, заметные пользователю. Опубликованные версии отмечают теги Git и выпуски GitHub.

## Не выпущено

### Добавлено

- Навык `asd-ste100-ru`. Навык переписывает русский текст по разделу 8.2 ГОСТ Р 58049—2017: последний ответ агента, текст после команды или файл.
- Раздел 8.2 ГОСТ Р 58049—2017 дословно, со всеми 14 примерами.
- Скрипт `utr_check.py`. Скрипт проверяет длину предложений и абзацев, концы пунктов списка и текст ссылок.
- Установка через маркетплейсы Claude Code, Codex и Cursor.
- Иконки навыка и стартовый запрос для Codex.
- Страница навыка `docs/skills/asd-ste100-ru.md`.
- Ручные проверочные кейсы на примерах ГОСТа.
- Проверка структуры репозитория в GitHub Actions.
- Лицензия MIT. Текст ГОСТа не входит в лицензию.
- Четыре кейса для ответов агента: просьбы в тексте, оценки риска, код, ошибки и несколько исполнителей.

### Изменено

- Навык лежит в папке `skills/asd-ste100-ru`. Установка командой `git clone` в папку навыков больше не работает: используйте `npx skills` или маркетплейс.
- README стал короче. Сценарии, правила и скрипт описаны на странице навыка.
- Навык считает исходный текст данными. Просьбы внутри него не выполняет; оценки риска и уверенности сохраняет.
- Параметр `--правки` включает таблицу правок. Его ставят перед текстом или путём.
- README указывает команду вызова для каждого агента.
- Скрипт учитывает ограждения кода, встроенный код, сокращения, предложения в скобках и числа с разделителями разрядов.
