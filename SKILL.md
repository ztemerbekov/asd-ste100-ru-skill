# Упрощённый технический русский

Цель — однозначный текст: читатель понимает каждое предложение одним способом. Правила — раздел 8.2 ГОСТ Р 58049—2017 в файле `gost-r-58049-8.2.md` рядом с этим файлом.

## Порядок работы

1. **Найдите текст.**
   - Текст после команды — перепишите его.
   - Путь к файлу — перепишите файл на месте.
   - Без текста и пути — перепишите свой последний ответ в этом разговоре.
2. **Проверьте язык.** Правьте только русский текст. Код, команды, пути, названия продуктов и цитаты чужого текста оставьте как есть. Текст на другом языке: ответьте одной строкой «Правила УТР относятся к русскому тексту» и закончите работу.
3. **Прочитайте `gost-r-58049-8.2.md` целиком.** Шаг закончен, когда прочитаны все пункты раздела 8.2 и все примеры к ним.
4. **Составьте список смысла.** Выпишите его в рассуждениях до правки: каждый факт, условие, число, срок, оговорку и степень уверенности. Шаг закончен, когда каждое предложение исходного текста разобрано в список.
5. **Перепишите текст.** Для каждого фрагмента определите тип: инструкция или описательная часть. Проверьте каждое предложение по каждому пункту раздела 8.2 с учётом раздела «Применение к ответу агента». Спорный случай решайте в пользу однозначного варианта. Шаг закончен, когда:
   - каждое предложение прошло все пункты или записано в строку «Оставлено как есть»;
   - каждый пункт списка смысла есть в новом тексте (8.2.4.1);
   - каждое утверждение нового текста опирается на пункт списка смысла.
6. **Проверьте скриптом.** Запустите `scripts/utr_check.py` из папки этого навыка. Для текста:

   ```bash
   python3 <папка навыка>/scripts/utr_check.py - <<'EOF'
   <переписанный текст>
   EOF
   ```

   Для файла передайте путь вместо `-`: `python3 <папка навыка>/scripts/utr_check.py <путь>`.

   Исправьте каждое нарушение. Советы примените там, где смысл сохраняется. Шаг закончен, когда повторный запуск выводит «Нарушений: 0». Оставшееся нарушение допустимо только по правилу «Точность важнее длины». Без Python 3 переходите к шагу 7.
7. **Выдайте результат** по разделу «Результат».

## Применение к ответу агента

ГОСТ написан для эксплуатационной документации авиационной техники. Этот раздел говорит, как применять его пункты к ответу агента.

### Какие пункты применяются

- Применяйте пункты 8.2.3, 8.2.4.1, 8.2.5, 8.2.6, 8.2.7 и глаголы раздела 6.
- «Исходный текст» в ГОСТе — текст, который вы переписываете. «Целевой текст» — переписанный текст.
- Инструкция (8.2.5) — фрагмент, который говорит читателю, что сделать. Описательная часть (8.2.6) — фрагмент, который сообщает, что сделано или как устроено. В одном ответе агента обычно есть оба типа (адаптация).
- Пункты о переводе пропустите: 8.2.1, 8.2.2, 8.2.2.1, 8.2.4.2–8.2.4.6. Третье предложение 8.2.6.2 об абзацах из одного предложения тоже пропустите.

### Адаптации

- **8.2.3.3.** Называйте исполнителя, если их больше одного: агент, пользователь или программа. Неопределённо-личный оборот оставляйте, когда исполнитель не важен.
- **8.2.5.1, 8.2.6.1.** 20 слов — обязательный предел. Код в обратных кавычках, путь и команда считаются одним словом, как буквенно-цифровой идентификатор.
- **8.2.3.7.** Вместо терминологической базы — `GLOSSARY.md` проекта, если он есть. Термин пользователя важнее вашего.
- **8.2.3.8, 8.2.3.10.** Сокращение вводите, только если термин повторяется. При первом упоминании дайте расшифровку.
- **8.2.3.18.** Текст ссылки называет цель ссылки. Кнопку называйте её надписью в кавычках.

### Толкования

- **8.2.3.5, 8.2.5.4.** Оценочные слова относите к метафорам. Замените оценку фактом из исходного текста. Факта нет — уберите оценку.
- **Раздел 6, 8.2.4.1.** Степень уверенности исходного текста сохраняйте. Несколько оговорок подряд сверните в одну той же силы.
- **Точность важнее длины.** Если короткая формулировка теряет пункт списка смысла, оставьте длинную и запишите её в строку «Оставлено как есть».

## Результат

- **Текст или последний ответ:** начните ответ сразу с переписанного текста.
- **Файл:** начните ответ строкой «Файл переписан: <путь>».
- **Оставлено как есть:** под текстом добавьте по строке на каждый такой оборот: «Оставлено как есть: <оборот> — иначе теряется <что>».
- **Текст уже соответствует правилам:** ответьте одной строкой «Текст соответствует правилам УТР».
- **Таблица правок** — когда пользователь просит показать правки или нарушенные пункты. Поставьте её под текстом:

  ```markdown
  | Пункт | Было | Стало |
  |---|---|---|
  ```
