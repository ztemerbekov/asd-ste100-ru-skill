# Переписывайте ответы ИИ-агента на однозначный русский

**asd-ste100-ru** — навык для Claude Code, Codex и Cursor по разделу 8.2 ГОСТ Р 58049—2017.

Ответ агента непонятен — вызовите навык командой. Навык перепишет ответ на упрощённый технический русский (УТР). Каждое предложение читается одним способом.

- **Переписывает.** Последний ответ агента, ваш текст или файл. Предложение — не больше 20 слов, исполнитель назван, одно понятие — один термин.
- **Сохраняет смысл.** До правки агент выписывает каждый факт, условие, число и оговорку. Новый текст содержит каждый пункт и не добавляет новых.
- **Показывает пункты ГОСТа.** По вашей просьбе агент выдаёт таблицу правок. Каждая правка ссылается на пункт раздела 8.2.

**Ваша первая команда**

> `/asd-ste100-ru`

Навык перепишет последний ответ агента в этом разговоре.

## Что умеет навык

1. **Переписывает последний ответ агента.** Вызовите навык без текста.
2. **Переписывает ваш текст.** Поставьте текст после команды.
3. **Переписывает файл на месте.** Поставьте путь к файлу после команды.
4. **Показывает правки.** По вашей просьбе агент выдаёт таблицу «Пункт | Было | Стало».
5. **Проверяет строение текста скриптом.** Скрипт проверяет длину предложений и абзацев, концы пунктов списка и текст ссылок.

## Быстрый старт

1. Откройте терминал. Установите навык для Claude Code, Codex и Cursor:

   ```bash
   npx skills@latest add ztemerbekov/asd-ste100-ru-skill -g -a claude-code -a codex -a cursor
   ```

   Чтобы позже получить обновления, выполните `npx skills update`.

2. Откройте новую сессию агента.

3. Вызовите навык. Текст для переписывания поставьте в то же сообщение после команды:

   > `/asd-ste100-ru`
   >
   > `[вставьте текст]`

   Команда в каждом агенте:

   | Агент | Команда |
   |---|---|
   | Claude Code | `/asd-ste100-ru` |
   | Codex | `$asd-ste100-ru` |
   | Cursor | `/asd-ste100-ru` |

## Как навык меняет текст

**Агент читает правила целиком.** Перед правкой агент читает раздел 8.2 и все примеры к нему.

**Агент составляет список смысла.** В список входит каждый факт, условие, число, срок, оговорка и степень уверенности исходного текста.

**Агент проверяет каждое предложение по каждому пункту.** Новый текст содержит каждый пункт списка смысла. Каждое утверждение нового текста опирается на пункт списка.

**Скрипт проверяет результат.** Агент запускает `scripts/utr_check.py` и исправляет каждое нарушение. Без Python 3 агент пропускает этот шаг.

**В ответе — только текст.** Агент не пишет вступление, пересказ правок и предложения помочь ещё.

## Правила

Правила — раздел 8.2 ГОСТ Р 58049—2017 дословно, вместе со всеми 14 примерами стандарта: [`gost-r-58049-8.2.md`](gost-r-58049-8.2.md).

ГОСТ написан для эксплуатационной документации авиационной техники. Применение пунктов к ответу агента описано в [`SKILL.md`](SKILL.md), раздел «Применение к ответу агента». Пункты о переводе навык не применяет.

Часть пунктов навык адаптирует:

- **8.2.3.3 — исполнитель назван.** ГОСТ предписывает неопределённо-личные конструкции: в руководстве по обслуживанию исполнитель один. В ответе агента действуют агент, пользователь и программы.
- **8.2.5, 8.2.6 — тип выбирается для фрагмента.** В одном ответе агента обычно есть и инструкция, и описательная часть.
- **8.2.5.1, 8.2.6.1 — 20 слов обязательно.** ГОСТ рекомендует этот предел. Код, путь и команда считаются одним словом, как буквенно-цифровой идентификатор.
- **8.2.3.7 — термины из глоссария проекта.** Вместо терминологической базы навык берёт файл `GLOSSARY.md` проекта, если файл есть.
- **8.2.3.8, 8.2.3.10 — сокращение только с расшифровкой.** Читатель ответа не держит в памяти список сокращений, в отличие от читателя руководства.
- **8.2.3.18 — текст ссылки называет цель.** Навык применяет пункт к ссылкам в Markdown.

## Скрипт проверки

Скрипт `scripts/utr_check.py` проверяет строение текста. Нужен Python 3, сторонние библиотеки не нужны.

```bash
python3 scripts/utr_check.py текст.md
```

Вывод скрипта для двух исходных текстов из примеров ГОСТа, пункты 8.2.7 и 8.2.3.11:

```text
текст.md:1 длина: 39 слов, больше 20. Разделите предложение. (8.2.5.1, 8.2.6.1)
текст.md:3 совет: отглагольное: «осуществляет корректировку»: используйте глагол вместо отглагольного существительного. (8.2.3.10)
текст.md:3 совет: причастие: Причастный оборот «выполнивший». Замените придаточным или отдельным предложением, если смысл сохранится. (8.2.3.11)
Нарушений: 1. Советов: 2.
```

Другие способы запуска:

- `python3 scripts/utr_check.py - < текст.md` — текст из стандартного ввода;
- `python3 scripts/utr_check.py --json текст.md` — результат в JSON;
- `python3 scripts/utr_check.py --selftest` — самопроверка скрипта.

**Нарушения** — правила, которые скрипт проверяет надёжно:

- длина предложения больше 20 слов;
- больше 6 предложений в абзаце;
- пункт списка оборван на «и» либо на «или»;
- текст ссылки «здесь» либо «ссылка».

**Советы** — места, которые скрипт находит по окончаниям слов. Здесь скрипт может ошибиться:

- причастные и деепричастные обороты;
- страдательный залог;
- отглагольное существительное после «осуществлять», «производить», «проводить», «выполнять».

Скрипт пропускает блоки кода и служебный заголовок файла. Код выхода 1 означает, что есть нарушения. Советы на код выхода не влияют.

Жаргон, метафоры, оценки и синонимы скрипт не проверяет: у каждого проекта свой словарь. Эти правила проверяет агент. Глаголы раздела 6 ГОСТа («должно», «необходимо», «следует», «может») скрипт не отмечает никогда.

## Обратите внимание

**Навык не включается сам.** Агент применяет правила УТР только после вашей команды.

**Навык правит только русский текст.** На текст на другом языке агент ответит строкой «Правила УТР относятся к русскому тексту».

**Код остаётся как есть.** Навык не меняет код, команды, пути, названия продуктов и цитаты чужого текста.

**Точность важнее длины.** Если короткая формулировка теряет факт, агент оставит длинную. Такое предложение может превысить 20 слов.

**Файл меняется на месте.** Сохраните исходную версию файла до вызова навыка.

**Навык не заменяет стандарт.** Навык не готовит эксплуатационную документацию по ГОСТ и не подтверждает соответствие стандарту.

**Навык не для рекламы.** УТР убирает оценки и образные выражения. Для рекламы и текстов клиентам навык не предназначен.

## Обновление и удаление

Обновляйте навык тем же способом, которым установили его.

Если вы использовали [быстрый старт](#быстрый-старт), обновите навык одной командой:

```bash
npx skills update
```

Удалите навык:

```bash
npx skills remove asd-ste100-ru -g
```

Если вы ставили навык через `git clone`, обновите его командой `git pull` в папке навыка.
