# Упрощённый технический русский для ИИ-агентов

Навык заставляет ИИ-агента отвечать на однозначном русском по разделу 8.2 ГОСТ Р 58049—2017. Правила: не больше 20 слов в предложении, названный исполнитель, одно слово на одно понятие, без жаргона и метафор.

Пример из ГОСТ Р 58049—2017, пункт 8.2.3.13:

- **Исходный текст:** «На базе доработанного по замечаниям экспертизы перевода подготавливается окончательная редакция проекта»
- **Текст, отредактированный согласно правилам УТР:** «Переводчик дорабатывает окончательную редакцию проекта после экспертизы»

## Как работает

Вы вызываете навык командой. Навык переписывает:

- текст, который вы написали после команды;
- файл, если вы указали путь;
- последний ответ агента, если вы не дали ни текста, ни пути.

В ответ агент выдаёт только переписанный текст. Попросите «покажи правки» — агент выдаст таблицу с номерами пунктов ГОСТа. Если агент оставил оборот длиннее ради точности, он сообщит об этом одной строкой.

Навык работает в Claude Code, Codex и Cursor. Сам навык не включается: только по вашей команде.

## Установка

Одной командой для трёх агентов:

```bash
npx skills add ztemerbekov/asd-ste100-ru-skill -g -a claude-code -a codex -a cursor
```

Без `npx` склонируйте репозиторий в папку навыков. Имя папки должно совпадать с именем навыка — `asd-ste100-ru`.

Claude Code:

```bash
git clone https://github.com/ztemerbekov/asd-ste100-ru-skill ~/.claude/skills/asd-ste100-ru
```

Codex и Cursor:

```bash
git clone https://github.com/ztemerbekov/asd-ste100-ru-skill ~/.agents/skills/asd-ste100-ru
```

## Правила

Правила — раздел 8.2 ГОСТ Р 58049—2017 дословно, вместе со всеми 14 примерами стандарта: [`gost-r-58049-8.2.md`](gost-r-58049-8.2.md).

ГОСТ написан для эксплуатационной документации авиационной техники. Как навык применяет его к ответу агента, описано в [`SKILL.md`](SKILL.md), раздел «Применение к ответу агента». Пункты о переводе навык не применяет. Часть пунктов адаптирована:

- **8.2.3.3 — исполнитель назван.** ГОСТ предписывает неопределённо-личные конструкции: в руководстве по обслуживанию исполнитель один. В ответе агента действуют агент, пользователь и программы.
- **8.2.5, 8.2.6 — тип выбирается для фрагмента.** В одном ответе агента обычно есть и инструкция, и описательная часть.
- **8.2.5.1, 8.2.6.1 — 20 слов обязательно.** ГОСТ рекомендует этот предел. Код, путь и команда считаются одним словом, как буквенно-цифровой идентификатор.
- **8.2.3.7 — термины из глоссария проекта.** Вместо терминологической базы — файл `GLOSSARY.md` проекта, если он есть.
- **8.2.3.8, 8.2.3.10 — сокращение только с расшифровкой.** Читатель ответа не держит в памяти список сокращений, в отличие от читателя руководства.
- **8.2.3.18 — текст ссылки называет цель.** Навык применяет пункт к ссылкам в Markdown.

## Скрипт проверки

Скрипт `scripts/utr_check.py` проверяет строение текста. Нужен Python 3, сторонние библиотеки не нужны.

```bash
python3 scripts/utr_check.py текст.md
```

Другие способы запуска:

- `python3 scripts/utr_check.py - < текст.md` — текст из стандартного ввода;
- `python3 scripts/utr_check.py --json текст.md` — результат в JSON;
- `python3 scripts/utr_check.py --selftest` — самопроверка скрипта.

Вывод скрипта для двух исходных текстов из примеров ГОСТа, пункты 8.2.7 и 8.2.3.11:

```text
текст.md:1 длина: 39 слов, больше 20. Разделите предложение. (8.2.5.1, 8.2.6.1)
текст.md:3 совет: отглагольное: «осуществляет корректировку»: используйте глагол вместо отглагольного существительного. (8.2.3.10)
текст.md:3 совет: причастие: Причастный оборот «выполнивший». Замените придаточным или отдельным предложением, если смысл сохранится. (8.2.3.11)
Нарушений: 1. Советов: 2.
```

Нарушения — правила, которые скрипт проверяет надёжно:

- длина предложения больше 20 слов;
- больше 6 предложений в абзаце;
- пункт списка оборван на «и» или «или»;
- текст ссылки «здесь» или «ссылка».

Советы — места, которые скрипт находит по окончаниям слов и может ошибиться:

- причастные и деепричастные обороты;
- страдательный залог;
- отглагольное существительное после «осуществлять», «производить», «проводить», «выполнять».

Скрипт пропускает блоки кода и служебный заголовок файла. Код выхода 1 означает, что есть нарушения. Советы на код выхода не влияют.

Жаргон, метафоры, оценки и синонимы скрипт не проверяет: у каждого проекта свой словарь. Эти правила проверяет агент. Глаголы раздела 6 ГОСТа («должно», «необходимо», «следует», «может») скрипт не отмечает никогда.

## Источник

ГОСТ Р 58049—2017 «Перевод эксплуатационной документации на изделия авиационной техники с/на иностранные языки. Общие положения». Стандарт утверждён и введён в действие приказом Росстандарта от 29 декабря 2017 г. № 2129-ст.

Раздел 8.2 «Общие требования к упрощенному техническому русскому языку» приведён в [`gost-r-58049-8.2.md`](gost-r-58049-8.2.md) дословно. Это неофициальный текст: он не является официальным изданием стандарта и не входит в лицензию этого репозитория. Официальный текст распространяет ФГБУ «Институт стандартизации».
