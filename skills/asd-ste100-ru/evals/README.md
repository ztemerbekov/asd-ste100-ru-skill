# Проверка навыка asd-ste100-ru

Ручной набор кейсов проверяет поведение навыка без эталонного ответа. Кейсы — материал для сопровождающего. Навык не читает эти файлы.

Каждый входной текст — исходный текст примера из раздела 8.2 ГОСТ Р 58049—2017, дословно. Своих примеров в наборе нет.

## Когда запускать

Запускайте набор только по просьбе сопровождающего, например перед выпуском. Для узкого вопроса выберите кейсы, которые отвечают на этот вопрос. Полный запуск — все кейсы ниже.

## Как запускать

1. Откройте новую сессию агента с установленным навыком.
2. Выполните раздел «Подготовка», если он есть в кейсе.
3. Отправьте команду из раздела «Запрос пользователя». Входной текст поставьте в то же сообщение после команды.
4. Сохраните ответ агента.
5. Отметьте каждый пункт разделов «Должно измениться», «Должно сохраниться» и «Запрещено». Спорный пункт считается проваленным.

Запишите в описание пул-реквеста или выпуска: цель запуска, номера кейсов, агента, модель, версию навыка, результат по каждому пункту и ограничения. Отчёты о запусках в репозиторий не добавляйте.
