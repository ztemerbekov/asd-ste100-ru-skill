# utr-risk-confidence-012 — риск и степень уверенности

- ID: `utr-risk-confidence-012`
- Источник: составленный пример ответа агента об оценке риска.
- Пункты: 8.2.4.1; толкование о сохранении оценок.
- Риск: агент убирает степень риска, автора оценки или оговорку.

## Запрос пользователя

```text
$asd-ste100-ru --правки
```

## Входной текст

```text
По оценке пользователя, риск потери данных высокий, однако причина пока не подтверждена, и я лишь допускаю, что сбой связан с обновлением.
```

## Должно измениться

- [ ] Длинное предложение разделено без потери смысла.
- [ ] Под текстом есть таблица правок с пунктами ГОСТа.

## Должно сохраниться

- [ ] Пользователь оценивает риск потери данных как высокий.
- [ ] Причина пока не подтверждена.
- [ ] Агент допускает связь сбоя с обновлением, но не утверждает её.

## Запрещено

- [ ] Удаление или ослабление слова «высокий».
- [ ] Приписывание оценки риска агенту.
- [ ] Представление гипотезы как установленной причины.
- [ ] Числовая вероятность, которой нет во входном тексте.
