# utr-file-in-place-010 — файл переписан на месте

- ID: `utr-file-in-place-010`
- Пункты: 8.2.5.1, 8.2.6.1
- Риск: агент выдаёт текст в ответе или создаёт новый файл вместо правки на месте.

## Подготовка

В папке проекта создайте файл `проверка.md` с входным текстом.

## Запрос пользователя

```text
/asd-ste100-ru проверка.md
```

## Входной текст

Исходный текст примера к пункту 8.2.6.1.

```text
Обратите внимание, что аккумуляторные батареи 15-СЦС-45 необходимо выпускать в сухом состоянии (не залитые электролитом)
```

## Должно измениться

- [ ] Файл `проверка.md` переписан на месте.
- [ ] Ответ — одна строка «Файл переписан: проверка.md».

## Должно сохраниться

- [ ] Обозначение `15-СЦС-45` без изменений.
- [ ] Батареи выпускают в сухом состоянии, без электролита.

## Запрещено

- [ ] Новый файл рядом с `проверка.md`.
- [ ] Переписанный текст в ответе.
- [ ] Факты, которых нет во входном тексте.
