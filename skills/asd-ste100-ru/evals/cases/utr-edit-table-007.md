# utr-edit-table-007 — таблица правок по просьбе

- ID: `utr-edit-table-007`
- Пункты: 8.2.3.11, 8.2.3.13, 8.2.3.14
- Риск: агент выдаёт таблицу без номеров пунктов или ссылается на пункты о переводе.

## Подготовка

Отправьте команду и входной текст одним сообщением. После ответа агента отправьте вторым сообщением: «покажи правки».

## Запрос пользователя

```text
/asd-ste100-ru
```

## Входной текст

Исходный текст примера к пункту 8.2.3.14.

```text
Перед началом работы по монтажу металлопластиковых труб к поверхности необходимо определить диаметр специальной клипсы, которая выбирается, учитывая размер самой трубы
```

## Должно измениться

- [ ] Первый ответ — только переписанный текст.
- [ ] Второй ответ содержит таблицу со столбцами «Пункт», «Было», «Стало».
- [ ] Каждая строка таблицы называет пункт раздела 8.2 или раздел 6.

## Должно сохраниться

- [ ] Диаметр специальной клипсы определяют перед монтажом металлопластиковых труб к поверхности.
- [ ] Клипсу выбирают с учётом размера трубы.

## Запрещено

- [ ] Строки таблицы со ссылками на пункты 8.2.1, 8.2.2, 8.2.2.1, 8.2.4.2–8.2.4.6.
- [ ] Таблица правок в первом ответе.
- [ ] Факты, которых нет во входном тексте.
